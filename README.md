A Co-op Multiplayer Mod for Nuclear Throne Ultra Mod.

# Prerequisites
 You must download the base game files from the Nuclear Throne Ultra Mod Itch.io Download Page. and the exe file in the releases here.
make sure to download NuclearThroneUltraMod_29_0.120.zip.
and the Vanilla Nuclear throne

# Installation Steps
1. Locate Your Game Folder
 Find the main directory where your Nuclear Throne is installed on your computer.
 Steam Users: You can safely apply this mod directly to your Steam version. To find your folder:
	1. Right-click Nuclear Throne in your Steam Library.
	2. Select Manage > Browse local files.

2. Download the Co-op Mod File
 Download the custom coop file here: [Download NTUM Co-op data.win](https://github.com/immortalCoop/NTUM-Coop/releases/tag/v.29.120)


3. Replace the Original File
 Go inside your game folder and locate the original file named data.win.
 Drag and drop the newly downloaded data.win file into that folder.
 Choose "Replace the file in the destination"
 and put the exe file there too

4. Launch and Play

 Open the game executable as you normally would.
 and enjoy:D
